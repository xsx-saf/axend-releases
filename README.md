# Axend — downloads

Get the latest version from **[Releases](../../releases/latest)**: download `Axend.exe` and run it. It installs itself to `%LOCALAPPDATA%\Axend` and adds itself to the Start menu.

Axend keeps everything on your computer. It goes online only to check for a newer version here (and, later, to activate a licence) — never with your data.

Updates: from version 4.13.0 on, Axend checks this page by itself and offers to update. Every download is checked against its SHA-256 before it runs.

This repository holds downloads only. The source code is private.

**Windows may warn** that it's from an unknown publisher, because the app isn't code-signed yet. Choose **More info → Run anyway**.
